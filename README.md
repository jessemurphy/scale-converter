# Scale Converter

A model-scale converter PWA: pick a scale (1:87 HO, 1:48 O, 1:64, 1:24, or any
custom ratio), then convert real-world sizes to model sizes and back. Includes
a "what scale is it?" mode — measure the real thing and the model, get the
ratio and the closest common scale.

- Model sizes shown in mm and fractional inches (nearest 1/32″)
- Real sizes shown in sensible units (feet + inches above a foot)
- Quick chips for favorite scales; the last scale used is remembered
- Fully offline after first load (service worker); no accounts, no server

## Hosting

Static files — GitHub Pages serves it as-is (Settings → Pages → Deploy from a
branch → main / root). On iPhone: open the URL in Safari → Share →
Add to Home Screen.
